# Personal Portfolio / 个人主页

A personal portfolio site showcasing avatar, bio, links, publications, projects, and interests.

展示个人头像，简介，链接，论文发表，项目经历，兴趣爱好等。

## Requirements / 要求

* Built with HTML + TailwindCSS + JS / 基于 html + tailwindcss + js
* Support Chinese name display with English content / 英文内容，姓名显示中文
* Dark/Light theme toggle / 支持深浅主题切换
* Extensible framework for plugins (e.g., three.js) / 框架支持扩展不同的插件，比如 three.js
* Deploy on GitHub Pages via GitHub Actions / 部署在github page上，通过github action生成静态网页并发布
* Local development with auto-open browser / 本地预览，dev 命令自动打开浏览器
* Clean and minimal code structure / 代码框架简洁

## Development / 开发

```bash
# Start dev server with auto-reload and auto-open browser
```
